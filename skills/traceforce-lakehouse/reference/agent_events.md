# agent_events

One row per OTLP log record or span, flattened from the raw activity objects in your bucket.
Types are Iceberg types; timestamps UTC. Generated by tools/gen_skill_reference.py.

No key: a session has many rows, a tool call has 1-3 rows (decision, result, span). Count distinct `session_id`,
`tool_call_id` or `coalesce(prompt_id, generation_id)` rather than rows when the question is about sessions, calls or prompts.
Codex's `user_prompt` rows carry neither id: count them by distinct `ts`. Sessions with only startup, hook or connection
events (no prompt, tool call, tokens or cost) are noise; the dashboards leave them out unless one has a
`traceforce.enforcement` or `postToolUseFailure` row (TraceForce blocked something, or a tool attempt failed).
Logs and spans upload independently, so a call may have only its span or only its decision row;
a span with no decision row is a gap, not an unapproved call. Cursor: only `postToolUse` rows carry
`tool_call_id`; its other hook rows (`beforeReadFile`, `afterShellExecution`, ...) are the same calls without one.

| column | type | meaning |
|---|---|---|
| `agent` | string | The agent's proto AgentIdentity name, e.g. AGENT_IDENTITY_CLAUDE_CODE, AGENT_IDENTITY_CLAUDE, AGENT_IDENTITY_CURSOR, AGENT_IDENTITY_GITHUB_COPILOT, AGENT_IDENTITY_CHATGPT. |
| `agent_type` | string | `agent` lowercased without the AGENT_IDENTITY_ prefix (e.g. `claude_code`, `cursor`). Join on this, not on `agent`. |
| `device_native_id` | string | Device serial. Joins devices.device_native_id. |
| `device_uuid` | string | A stable per-install device GUID; NULL when the agent doesn't provide one. Prefer it over the serial when present. |
| `sandbox_native_id` | string | Always NULL today; joins sandboxes.sandbox_native_id. |
| `path_email` | string | Account email associated with the source object; NULL when unknown. Independent of `user_email`. |
| `path_org` | string | Vendor org id associated with the source object; NULL when absent. |
| `path_session` | string | Session id associated with the source object; NULL when unknown. |
| `upload_ts` | timestamp | When the source object was uploaded, UTC. |
| `source_object` | string | Storage path of the raw object this row came from. |
| `signal` | string | Whether the row is an OTLP `log` record or a `span`. |
| `user_email` | string | End-user email as reported by the agent; NULL when the agent reports none (see identity.md). |
| `agent_org_id` | string | The AI vendor's org id for the user (e.g. the Anthropic org for Claude); NULL when the agent reports none. |
| `user_id` | string | The AI vendor's user id; NULL when the agent reports none. |
| `session_id` | string | The conversation/session identifier. Joins agent_conversations.conversation_external_id. |
| `resource_session_id` | string | OTLP resource attribute `session.id`, a fallback source for `session_id`. Always NULL today. |
| `ts` | timestamp | Event time, UTC. |
| `end_ts` | timestamp | Span end time, UTC; NULL on logs. |
| `event_name` | string | Agent-specific event name (user_prompt, tool_decision, tool_result, api_request, api_error, preToolUse, ...). Vocabularies differ per agent. |
| `span_name` | string | Span name (spans only). |
| `operation` | string | Operation type per GenAI semconv (`chat`, `execute_tool`, `invoke_agent`); the cross-agent grouping key. NULL on non-GenAI rows (e.g. connection/session-lifecycle events). |
| `prompt_id` | string | Per-turn (request/response) identifier; NULL when the agent emits none. |
| `generation_id` | string | Per-turn identifier for agents that emit one instead of `prompt_id` (e.g. Cursor); NULL otherwise. |
| `tool_name` | string | The tool invoked. Claude Code MCP calls: the decision/result rows say `mcp_tool`, the span row of the same `tool_call_id` carries the MCP tool's name; the server is in `mcp_server_name`. |
| `tool_type` | string | Tool type (function, ...). |
| `tool_call_id` | string | Per-call id; equals connector_containment_findings.tool_use_id (join key). NULL when the agent emits none. |
| `mcp_server_name` | string | MCP server as configured on the device; joins lower(mcp_server_instances.mcp_native_id). Also set on Claude Code's `mcp_server_connection` rows (`operation` NULL), which are connections, not calls: filter `operation = 'execute_tool'` for calls. Some servers are the agent app driving itself, not the user's tools, and have no inventory row; match the name after turning every character but letters, digits, `_` and `-` into `_` (`Claude Browser` → `Claude_Browser`). Claude and Claude Code: `ccd_*`, `cowork`, `scheduled-tasks`, `hearthbot`, `claude-code-remote`, `Claude_Code_Remote`, `claude_ai_Claude_Docs`, and only `show_widget`/`read_me` of `visualize`, `preview_start`/`preview_stop`/`preview_list`/`preview_logs` of `Claude_Browser`/`Claude_Preview`, `read_terminal`/`open_terminal_tab`/`list_terminal_tabs`/`stop_terminal_tab` of `terminal`, `memory_read`/`memory_list`/`memory_write`/`memory_str_replace`/`memory_append`/`memory_delete` of `memory`. Codex (`-` read as `_`): `codex_app`, `codex_security`, `js_reset`/`js_add_node_module_dir` of `node_repl`/`cua_repl`, and OpenAI's own tools on `codex_apps` (`web_run`, `write_page_reference`, `create_plugin`, `update_app_permissions`, `save_site_version`, `create_source_repository_write_credential`, after the last `__` and leading `_`). Cursor: `cursor-app-control`, `cursor-backend-control`, `cursor-subscriptions`, and server-less `move_agent_to_root`/`move_agent_to_cloned_root`. Server-less plumbing on any agent: `ToolSearch`, `StructuredOutput`, `SubagentHandback`, `tool_search`, `tool_search_tool`, `message_compose_v1`, `present_files`. Decide per `tool_call_id` (Claude Code's log rows say `mcp_tool`; the span names the tool). |
| `tool_args` | string | Tool input, JSON text; occasionally plain text (e.g. a raw shell command). Large. A call's rows can differ (same `tool_call_id`): Claude Code's `tool_decision` row holds only `{mcp_server_name, mcp_tool_name}` for an MCP call and `{bash_command, full_command, description}` for Bash, its `tool_result` row the real arguments (a long Bash command abbreviated `…[N chars]`), its span `{command}` for Bash and none for MCP; Codex: `tool_result` only; Claude: `tool_call`; Cursor: `postToolUse`/`postToolUseFailure`. Prefer the result row, as the incident-triage dashboard does. |
| `tool_result` | string | Tool output; NULL when the agent doesn't emit it. Some agents (e.g. Claude Code) put it on the span row only, not the `tool_result` log row. Large. |
| `decision` | string | Permission decision as the agent recorded it (e.g. `accept`/`reject`, `approved`/`denied-interactively-by-user`); NULL when the agent records none. |
| `sd_enforcement` | string | TraceForce sensitive-data policy mode in force on the prompt (`warn` or `block`), not the outcome; NULL when no policy applied. |
| `containment_enforcement` | string | TraceForce containment policy mode in force on the tool call (`warn` or `block`), not the outcome; NULL when no policy applied. |
| `error_type` | string | Error class/type on error rows (e.g. `permission_denied`, `403`); NULL otherwise. |
| `model` | string | The model requested for the turn; selector values such as `default` or `auto` mean auto-select, not a model name. |
| `input_tokens` | long | Uncached input tokens for the request (cache reads and writes are not included); NULL when the agent reports no token counts. |
| `output_tokens` | long | Output tokens for the request; NULL when the agent reports no token counts. |
| `cache_read_tokens` | long | Cache-read tokens for the request; NULL when the agent reports no token counts. |
| `cost_usd` | double | Request cost in USD: the agent's own figure, else an estimate at public list price from `llm_model_prices` (exact `model` match). Not an invoice: discounts, plan allowances and priority pricing are not reflected. NULL when the agent reports none and no estimate applies (`invoke_agent` rows, agents billed in credits, models without a list price). |
| `content_input` | string | Prompt as a JSON message array; masked per matched value when the org redacts. Large. |
| `content_output` | string | Response as a JSON message array; masked per matched value when the org redacts. Large. |
| `service_name` | string | The emitting service's name (OTLP resource attribute); may name the collector rather than the agent. One agent can have rows from more than one source (for example its web chat history and its app's own telemetry); service_name tells them apart. |
| `service_version` | string | Version string of the emitter — the agent, or the collector when it emits on the agent's behalf. |
| `os_type` | string | Operating system of the device; NULL when not reported. |
| `attrs_json` | string | Every other record attribute as JSON text: json_extract_scalar(attrs_json, '$["cursor.version"]'). The decision source lives here: $.source. Where present, $["traceforce.record.id"] with any trailing '#meta' removed is the same in every copy of a record; dedupe on that, preferring a copy without '#meta' (a '#meta' copy has no file text), then the newest upload_ts. Read it with JSON functions, not as text: its escaping, key order and number format differ by cloud. |
| `resource_json` | string | Every resource attribute as JSON text. Read it with JSON functions, not as text: its escaping, key order and number format differ by cloud. |
| `ingested_at` | timestamp | When the row was loaded, UTC. |
